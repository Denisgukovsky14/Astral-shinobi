# План на 3 дня: играбельный Android-билд, 5 уровней, без арта

Цель: APK на телефоне, в котором можно пройти 5 уровней подряд (убил всех → ключ → дверь → дальше), проиграть
(экран смерти, «Заново»), выиграть (экран «Игра пройдена») и начать сначала. Арта, звука, меню, сохранений нет.

Обозначения: **Д** — Денис, **К** — Клод. Оценки мои, рассчитаны на несколько часов работы в день; главный
источник риска — первая сборка под Android и сами уровни.

## Что в игре уже есть, а чего не хватает до билда

Есть: бой (мечник, кунайщик, лучник), координация и дремлющие враги, парирование, здоровье, экран смерти, шаблон
уровня, ключ и дверь, экран «Игра пройдена», кнопки скорости (для разработчика).

Не хватает именно для телефона (найдено при разборе кода, на ПК не видно):
1. **Тап для парирования** читается через `Pointer.current.press` — это только **первый** палец. Пока палец лежит на
   джойстике, второй палец (тап) не засчитается. Нужно читать все касания (`Touchscreen.current.touches`).
2. **Частота кадров**: на Android по умолчанию 30 FPS. Нужно `Application.targetFrameRate = 60`, запрет сна экрана.
3. **Логи в горячих путях** (бросок кунайщика, отладка AIPath в `EnemyChaseStop`, оверлей `CombatDirector`) — на
   телефоне заметно тормозят. Убрать из релиза.
4. **Безопасная зона** (вырез/скругления): HUD слева-сверху и справа-сверху может уйти под вырез.
5. **Кнопка «Сначала»** в конце игры перезапускает *текущий* уровень, а не первый.
6. **Куда смотрит игрок**: на ПК он поворачивается за мышью, на телефоне только за движением. Парирование зависит от
   направления взгляда → решить, поворачивать ли его к направлению прицела, пока держится джойстик броска.
7. Порядок сцен в Build Settings, ориентация (ландшафт), имя пакета, иконка по умолчанию.

## День 1 — собрать Android и убрать мобильные блокеры

**Утро (Д, ~3 ч, с лимитом по времени):**
- [ ] Закоммитить текущее состояние.
- [ ] Unity Hub → установить Android Build Support (Android SDK & NDK Tools, OpenJDK) для 6000.2.6f2.
- [ ] Включить на телефоне «Отладку по USB», подключить, убедиться, что `adb devices` видит телефон.
- [ ] Player Settings: Landscape Left/Right, Scripting Backend IL2CPP, ARM64, Minimum API 26+, имя пакета
      `com.<ты>.astralshinobi`, Input System включён.
- [ ] Первая сборка **Build And Run на текущей `Coordination_Testing_Scene`** — только чтобы вскрыть проблемы
      инструментов. Если уходит больше 2 часов — присылай текст ошибки мне, не бейся один.

**Параллельно (К, пока Д собирает):**
- [ ] Парирование: тап любым пальцем (все касания).
- [ ] `targetFrameRate = 60`, `Screen.sleepTimeout = NeverSleep`, ориентация.
- [ ] Логи: убрать/спрятать за `#if UNITY_EDITOR`; оверлей директора выключить в релизе.
- [ ] Safe Area для HUD (полоска хп, счётчики, значок парирования, кнопки скорости).
- [ ] «Сначала» → загрузка первого уровня (поле `firstLevelScene` у `LevelManager`).
- [ ] Надпись «Уровень N из 5».
- [x] Поворот игрока по прицелу (сделано 2026-10-25: пока держится джойстик броска и нож в руке, игрок смотрит в сторону прицела; после броска остаётся повёрнутым так, как целился, пока не пойдёт или не начнёт целиться снова).

**Вечер (Д):** билд №1 на телефон. Проверить: оба джойстика, парирование вторым пальцем, FPS, не уходит ли HUD под
вырез. Вывод дня: *игра запускается на телефоне и управляется нормально.*

## День 2 — уровни 1–3 и первый прогон

**Д (основное время, ~1–1.5 ч на уровень):** собрать уровни 1–3 по [LEVELS.md](LEVELS.md): новый уровень из шаблона →
стены → дверь → враги → «Подогнать уровень». Рекомендуемая нарастающая сложность:
- Уровень 1: 1–2 мечника (учим двигаться, бросать нож, парировать).
- Уровень 2: мечник + лучник.
- Уровень 3: мечник + кунайщик + лучник, один дремлющий мечник.

**К (по запросам):** чинить, что вылезет при сборке уровней (непрямоугольные формы, размер сетки A*, застревания
врагов), правка баланса через публичные поля, решение по здоровью между уровнями (сейчас каждый уровень с полным хп —
для первой сборки можно оставить).

**Вечер (Д):** билд №2 (уровни 1–3, порядок сцен в Build Settings). Пройти на телефоне. Записать: где умер слишком
быстро/слишком легко, что неудобно в управлении, где лагает.

## Чек-лист «готово»

- [ ] APK ставится и запускается на твоём телефоне, ≥ 50 FPS на самом тяжёлом уровне.
- [ ] Пройден весь путь: уровень 1 → … → 5 → «Игра пройдена» → «Сначала».
- [ ] Смерть → «Заново» работает на всех пяти уровнях.
- [ ] Парирование тапом вторым пальцем работает.
- [ ] HUD не уходит под вырез, кнопки не перекрываются.

## Если не успеваем (что резать, в порядке отказа)

1. Уровни 5 → 3–4 (билд всё равно «дойти до конца»).
2. Safe Area (если на твоём телефоне нет выреза).
3. Поворот игрока по прицелу (оставить как есть).
4. Кнопки скорости убрать из релиза.

## Что сознательно НЕ делаем в этом билде

Арт и анимации, звук, главное меню, сохранения и прогресс, перенос здоровья между уровнями, зоны ответственности
и зрение/слух врагов, рикошеты кунайщика для сложной геометрии.
