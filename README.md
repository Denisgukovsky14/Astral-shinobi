# Astral Shinobi

2D-экшен с видом сверху про ниндзя и один зачарованный клинок: бросай его так, чтобы он отскакивал от стен и находил врагов за углами, а потом лови на лету.

## Геймплей

- **Рикошетный нож.** Прицеливание джойстиком показывает траекторию с одним отражением. Нож отскакивает от стен, бьёт врагов, а пойманный в воздухе возвращается без кулдауна. Бросок в слишком тесный угол запрещён, траектория при этом красная.
- **Bullet-time.** Прицеливание замедляет время на 1 секунду, потом время плавно возвращается к норме, даже если игрок продолжает целиться. Виньетка гаснет синхронно с этим. Обе длительности настраиваются в Инспекторе.

## Враги

| Враг | Поведение |
|---|---|
| **Мечник** | Преследует игрока, `AntiTricker` перехватывает тех, кто кружит вокруг колонн. |
| **Кунайщик** | Держится на кольце вокруг игрока и бросает кунаи по прямой и с рикошетом от стен. Сам ищет точку, откуда есть выстрел. |
| **Лучник** | Стреляет только по прямой, стрелы вдвое быстрее кунаев, держится дальше кунайщика. Тот же `AntiTricker`, но с рывком вдвое медленнее. |

У дальнобойных врагов есть защита от залипания у стен и «жёсткий пол» дистанции, чтобы они не таранили игрока.

## Технологии

- Unity 6000.2.6f2: URP, New Input System, TextMeshPro
- [A* Pathfinding Project](https://arongranberg.com/astar/): `AIPath` и `GridGraph`
- Joystick Pack для мобильного управления (также работают клавиатура и мышь)

## Запуск

1. Открой проект в Unity 6000.2.6f2.
2. Открой сцену `Assets/Scenes/Prorotype.unity`.
3. Нажми Play.
